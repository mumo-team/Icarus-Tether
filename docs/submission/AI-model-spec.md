# AI 모델 활용 및 라이선스 명세서

## 1. 개요

Icarus-Tether는 **핵심 보안 판정에 AI/LLM을 사용하지 않는다.** lethal trifecta 차단·오염 계보 추적·정화·HITL 등 모든 판정은 정책 엔진(`policy-engine`)의 **100% 결정론 코드**로 이뤄지며, 형식검증(TLA+)으로 안전 불변식이 증명돼 있다.

AI 모델은 **단 하나**, 보조적인 "ML 프롬프트 인젝션 탐지 신호"로만 사용한다. 이 신호가 없어도(또는 틀려도) 핵심 차단은 그대로 동작한다.

## 2. 사용 모델

| 항목 | 내용 |
|---|---|
| **모델명** | `protectai/deberta-v3-base-prompt-injection-v2` |
| **제공처** | ProtectAI (Hugging Face Hub) |
| **베이스 모델** | `microsoft/deberta-v3-base` (약 86M 파라미터) 파인튜닝 |
| **과제 유형** | 텍스트 분류 (text-classification) — 입력 텍스트가 프롬프트 인젝션인지 이진 판별 |
| **실행 형식** | ONNX (로컬 추론, `@huggingface/transformers` v3.8.1 / onnxruntime) |
| **모델 라이선스** | Apache-2.0 |
| **베이스 모델 라이선스** | MIT (Microsoft DeBERTa-v3) |
| **출처 URL** | https://huggingface.co/protectai/deberta-v3-base-prompt-injection-v2 |

## 3. 활용 방식

- **위치:** `proxy/src/injection.ts`
- **호출 방식:** `@huggingface/transformers`의 `pipeline("text-classification", ...)`로 **로컬 추론**. 외부 API·네트워크 전송 없음(모델은 최초 1회 다운로드 후 로컬 캐시).
- **입력:** 비신뢰 출처(웹 fetch·이메일 본문 등)로 판정된 도구 결과의 **콘텐츠 텍스트만**. 민감 데이터나 사용자 자격증명을 모델에 넣지 않는다.
- **출력:** INJECTION 라벨의 확률 점수(0~1). 임계값을 넘으면 "인젝션 의심" 신호.
- **소비처:** 이 점수는 대시보드(C)의 위협 융합 배너에 "ML 인젝션 탐지" 신호로 표시된다. 계보 판정·트라이펙타 차단과 **별개의 보조 신호**다.

## 4. 아키텍처상 위치 — "보조 신호"임을 명확히

```
핵심 판정(차단 결정) ── 정책 엔진(결정론, AI 0, TLA+ 증명)   ← 제품의 안전은 여기에 의존
보조 신호(참고 표시) ── ML 인젝션 탐지(이 모델)              ← 없어도/틀려도 핵심 차단 유지
```

- 제품의 보안 보장(lethal trifecta 차단)은 이 모델에 **의존하지 않는다.**
- 모델은 "이 콘텐츠가 인젝션처럼 보인다"는 **참고용 관측 신호**를 대시보드에 더해줄 뿐이다.

## 5. 데이터 처리·프라이버시

- 추론은 **전부 로컬**에서 수행된다(외부 모델 API 미사용). 입력 콘텐츠가 외부로 나가지 않는다.
- 모델에 넘기는 것은 비신뢰 출처 콘텐츠 텍스트뿐이며, 세션의 민감 데이터(고객정보 등)는 모델에 투입하지 않는다.

## 6. 현재 상태 및 한계 (정직한 고지)

- 현 개발 환경에서 fp32 ONNX 모델이 onnxruntime 파싱 단계에서 로드에 실패하는 이슈가 있다(해당 저장소에 양자화 ONNX 변형이 없어 대체 로드 불가).
- 이때 시스템은 **fail-safe**로 동작한다: 모델 판정 불가를 "안전"으로 조용히 넘기지 않고 "의심"으로 처리하며(`injection.ts`), **핵심 차단(결정론 엔진)은 영향을 받지 않는다.**
- 즉 이 모델은 **정상 동작 시 UX·관측을 강화하는 보조 신호**이고, 미동작 시에도 제품의 보안 판정은 그대로 유지된다.

## 7. 라이선스 준수

- 사용 모델(Apache-2.0)·베이스 모델(MIT)·실행 라이브러리 `@huggingface/transformers`(Apache-2.0) 모두 허용적 라이선스로, 본 프로젝트(Apache-2.0) 배포와 충돌하지 않는다.
- 모델 가중치는 저장소에 포함하지 않으며, 실행 시 Hugging Face Hub에서 내려받아 로컬 캐시한다.
